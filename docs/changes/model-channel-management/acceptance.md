## 如何查看

已有验收预览实例已关闭，没有仍在运行的专用预览地址。可先查看实施阶段截图：[桌面深色](/tmp/selfcraft-model-desktop-dark.png)、[移动端浅色](/tmp/selfcraft-model-mobile-light.png)、[移动端深色](/tmp/selfcraft-model-mobile-dark.png)、[墨白浅色](/tmp/selfcraft-model-ink-light.png)。截图来自隔离测试数据，保存在本机临时目录。

需要实际操作时，可在项目根目录启动独立数据目录的当前构建，端口由系统分配：

```bash
bun run build:web
model_acceptance_home=$(mktemp -d /tmp/selfcraft-model-acceptance.XXXXXX)
SELFCRAFT_ENV=development \
SELFCRAFT_HOME="$model_acceptance_home" \
SELFCRAFT_WEB_HOST=127.0.0.1 \
SELFCRAFT_WEB_PORT=0 \
bun run runtime
```

打开终端输出的 `Selfcraft Runtime 已就绪` 地址。结束时在该终端按 `Ctrl-C`，不会停止其他实例。这是启动说明，本轮 handoff 未执行启动或修改实际实例。

仅验收配置管理时，在首次配置创建 `dev` 渠道，选择 OpenAI Compatible、填写测试占位地址 `http://127.0.0.1:9/v1`，Key 留空，首个模型为 `model-a`，能力保留默认值。完成时区后可进入设置；此地址不提供模型服务，不用它判断连接是否成功，也不发送对话。需要验收实际连接时，再配置可用的测试服务。

优先手动走以下路径：

1. 从 `dev` 添加 `model-b`，确认表单没有地址和 Key；尝试再次新增渠道 `dev`，填写不同地址，确认报错且原连接不变
2. 删除默认 `model-a`，确认被阻止；把默认切到 `model-b`，再给 `model-a` 分别配置反思、整理用途，确认仍被阻止；解除引用后删除并刷新
3. 创建第二个渠道，取消随后的添加模型，确认空渠道保留；添加一个不被用途引用的模型后删除，确认渠道仍存在
