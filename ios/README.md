# Selfcraft iPhone

原生 SwiftUI 入口，最低 iOS 18、Swift 6，与 Web / CLI 使用同一个 Runtime。工程为 `Selfcraft.xcodeproj`，共享 scheme 为 `Selfcraft`，正文使用 MarkdownView；主依赖固定到提交 `700fe702a29349007a3e6ff5064e35128f8af0a6`，传递依赖由工程内的 `Package.resolved` 锁定。需要支持 Swift 6.2 的 Xcode 工具链。

品牌图统一取自 `web/public/brand/selfcraft-cloud.png`。App 内的 `Cloud` 图片保留原图，桌面图标 `AppIcon` 使用同一图片等比缩放到 1024 × 1024，保留原背景且无透明通道。更新 Web logo 时需同步这两份资源。

## 运行

1. 使用 Xcode 打开 `ios/Selfcraft.xcodeproj`，选择 `Selfcraft` scheme 和 iPhone 模拟器，运行 Debug
2. 启动已有本地测试 Runtime；模拟器连接 `http://127.0.0.1:3210`
3. 首次连接填写地址和 Runtime 访问凭证。凭证进入 Keychain，不存入 URL、UserDefaults 或草稿
4. 对话作为主页面，点击左上云朵打开近况、事项、记忆和设置；首次未配置模型时显示模型设置

如果实例尚未启用访问凭证，在**同一个实例的数据环境**执行：

```bash
bun run client:token
```

现有测试容器可使用 `docker exec selfcraft-selfcraft-1 bun run client:token`。此命令每次都会**轮换**凭证，并仅在终端显示新值；旧 App 凭证和 Web 会话立即失效，需要重新填写。测试实例已启用凭证，无需为了启动 App 再次轮换。不要提交凭证到仓库。

同机 CLI 自动读取本地实例凭证；远程 CLI 使用 `SELFCRAFT_RUNTIME_URL` 和 `SELFCRAFT_ACCESS_TOKEN`。Web 首次显示凭证输入框，登录后使用 HttpOnly Cookie。

真机需使用 Mac 可达的局域网地址，并配置 Xcode 签名与 Developer Mode。当前 Docker 只绑定 `127.0.0.1`，真机无法直接访问；需明确配置局域网监听或转发后再测试。Debug 允许本地 HTTP；Release 只接受 HTTPS，不能把公网 IP 等同于安全部署。

## 导航与输入

对话底部只保留一条输入区，通过麦克风 / 键盘按钮切换文字与按住说话，已有文字和图片草稿不会因切换丢失。上滑取消录音；VoiceOver 可双击开始、再次双击结束，并通过自定义操作取消。

标题栏中央展示品牌 Logo；左上侧栏图标直接打开大尺寸近况面板，不停留在半屏，显示最多两条未完成事项及一条当前认识；没有对应内容时只保留导航入口。事项、记忆和设置在面板内打开，对话仍保留原滚动位置。下滑或点击关闭按钮返回对话；录音中打开面板会保留为待确认草稿。最大辅助字号采用纵向品牌布局。

右上通知按钮显示未读提示，仅在前台且面板关闭时每 30 秒更新；关闭面板后立即重新读取。通知列表使用 Runtime 返回的 `items` 字段，与远程推送能力无关。

回复优先展示正文。工具过程收为一行状态，进行中显示当前步骤，结束后显示操作数量；点击打开大尺寸执行详情。参考来源放在正文下方，按完整网址去重并汇总来源与网站数量，点击查看各页面。长按消息可复制文字，长按回答可朗读或停止朗读；这些操作也提供 VoiceOver 自定义入口。

## 功能与数据边界

- 对话：历史、文字、图片、流式回复、工具活动、引用、Markdown 块级排版与代码块、停止回复、手动朗读
- 语音：按住录音、上滑取消、无障碍开始/结束按钮；两分钟上限和中断仅保留草稿；语音条默认不播放，下方展示转录文字
- 原件：16 kHz / 单声道 / 16 bit PCM WAV，Runtime 校验真实格式、时长和大小；单独删除原音不删除转录文字
- 恢复：本地原子保存发送意图、稳定 ID；回执查询后补发；采集时间起五分钟内自动补发，过期或中断草稿需确认
- 事项：读取 Work 的目标、完成条件、依据与下一步；补充和取消通过用户对话请求，沿用 Runtime 权限与版本约束
- 记忆：查询、来源和版本、候选确认、纠错/现实变化、常驻、忘记
- 设置：模型渠道和用途、独立转写服务、时区、搜索、浅深色和澄蓝/墨白、权限
- 连接：设置 → 开发选项 → 连接管理；按稳定实例身份隔离缓存、文字/图片草稿与待发送内容
- 通知：持久通知列表、逐条已读、详情定位，以及跨实例通知切换确认入口

App 磁盘只缓存最近 200 条消息，显示窗口最多保留 500 条，系统列表按需创建消息行。上翻历史时新消息不会打断阅读，点击「回到最新消息」恢复最新窗口。完整历史仍在 Runtime。原始音频保存在实例 `audio/`，转写和处理状态保存在现有状态数据库；不把原音作为语言模型输入，也不在手机保存供应商密钥。

## 语音识别

在「设置 → 语音识别」配置 `https://api.siliconflow.cn/v1`、`FunAudioLLM/SenseVoiceSmall` 和密钥。Runtime 使用 AI SDK `transcribe()` 与 OpenAI 转写适配器，自定义地址，首版只发送 `file`、`model`。后续可更换支持该协议的供应商；不同协议仍需对应 SDK adapter。

供应商凭证只写入 Runtime `config/secrets.json`。失败会保留原件；成功结果持久缓存，重复转写不重复调用供应商。已有临时测试凭证可从此页面更新，不需要改源码。

## 性能与恢复

草稿和待发送内容与历史缓存分文件保存。草稿连续输入合并 300ms 后保存；发送意图立即排队写入，成功后才发送网络请求。历史缓存最多约每两秒合并写入一次，回复完成时立即提交。编码、缩图与文件写入离开主线程；退出前台会申请有限后台时间补写草稿。

流式快照只更新变化行，空心跳不触发写盘。Runtime 为版本查询建立索引，每批补读最多 100 条，游标只推进到本批已交付版本。图片缩略图缓存上限为 24MB，暂停与继续原音播放复用播放器。

流式正文由 MarkdownView 在后台增量解析，稳定块复用；完成态首次布局同步解析，结果保存在有界消息窗口中的 MessageItem，行视图重建时直接复用，避免先显示空白再撑高。解析文档与宽度、字号无关，实际布局仍随环境变化。每条回复独立持有流式源，短追加最多分四批、每批约 40ms 显示；调度延迟后按截止时间补齐，完成、中断、替换、大批补读及减少动态效果模式立即提交全文。该缓冲只影响显示，不修改消息缓存与服务端游标。自动跟随仅响应尾部消息高度、新尾消息及待发送数量变化，不再订阅全列表总高度；触摸开始、拖动和惯性滚动期间取消定位请求。

可运行 `bun run bench:conversation` 复现独立万条消息查询基准，不修改当前实例。[性能优化记录](../docs/ios-performance.md)列出测量结果与验证范围。

## 工程分工

| 目录 | 职责 |
| --- | --- |
| `Models` | 连接、消息、待发送条目和 JSON DTO |
| `Services` | HTTP/SSE、Keychain、本地文件、连接管理和音频 |
| `Features` | 会话状态及四个入口页面 |
| `Shared` | Selfcraft 语义色、文字渲染 |
| `SelfcraftTests` | 实例隔离、合并去重、补发边界和草稿保护 |

## 验证与已知边界

Xcode 中运行 `SelfcraftTests`；Runtime 在相同测试环境执行 `bun run smoke:mobile`，它会在真实对话中增加带测试标识的消息，并调用已配置模型。不会清空历史。

实际结果见 [验收记录](../docs/ios-validation.md)。目前通过模拟器和测试容器验收，不等于完整真机回归：真实麦克风、来电/锁屏、网络切换、动态字号和 VoiceOver 尚需真机确认。Markdown 已支持标题、列表、引用、链接、表格与围栏代码；宽表格和代码在各自区域横向滚动。公式与 Mermaid 尚未启用，代码保留等宽原文而不做语法高亮。

APNs 按用户决定保留设计并暂缓：已实现权限与通知定位入口，**尚未实现设备 token 注册、Runtime APNs 投递及签名 entitlement**，不能接收 App 关闭后的真实远程推送。后续开通开发者能力时按[方案](../docs/ios-app-plan.md)补齐并验收。BLE 硬件接入、Android、完整英文翻译和 App Store 分发不在本次验收内。
